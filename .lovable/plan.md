
# Personalized Prep Tracks — Plan

## What we're building
A new "Learn" experience inside the Preparation section where each student picks a track (e.g. Java, Python, Web, DSA, DBMS, OS, CN), takes a short **placement quiz** to find their level, then gets a **daily task plan** (length chosen by the user: 1 / 2 / 4 weeks). Each daily task is **one question + one practice problem**, generated by AI and **anchored to a curated trusted-source link** (W3Schools, MDN, GFG, JavaTpoint, etc.) so the user can read the official explanation. The user pastes their answer/code into a box, AI grades it, awards **karma**, and level/difficulty adapts. When a plan finishes, the user is promoted to the next level with a new path.

## User flow
1. **Track picker** — grid of tracks filtered to be relevant to the user's `branch` + `interests` from `profiles`. AI is shown as common to all.
2. **Placement quiz** — 5 adaptive MCQs (easy → medium → hard) to estimate level: Beginner / Intermediate / Advanced.
3. **Plan setup** — user picks pace: 1 / 2 / 4 weeks, 1 task/day. App generates a curriculum outline (list of subtopics across the days).
4. **Daily task screen** —
   - One concept question + one short coding/written exercise.
   - "📖 Read source" button → opens the curated reference page in a new tab.
   - Submission box (code or text). Run **AI verification** → score 0–100, strengths, mistakes, hint.
   - On pass (≥70) → mark day complete, award karma (`+5` easy, `+10` medium, `+15` hard), bump streak.
5. **Progress view** — calendar of completed days, current level, accuracy %, karma earned, "Next level unlocks in X days".
6. **Level up** — on plan completion, congratulations screen → next level path generated automatically.

## Technical design

**New tables** (via migration):
- `learning_tracks` (seed data): `id, slug, name, category, icon, description, source_base_url`. Pre-seeded with curated tracks and trusted base URLs per topic.
- `track_topics` (seed): `track_id, slug, title, level (beginner/intermediate/advanced), order_index, source_url` — the curated link bank.
- `user_learning_plans`: `id, user_id, track_id, level, pace_days, started_at, completed_at, status, current_day`.
- `daily_tasks`: `id, plan_id, day_number, topic_id, question, expected_answer_summary, exercise_prompt, source_url, generated_at`.
- `task_submissions`: `id, task_id, user_id, submission_text, ai_score, ai_feedback, passed, submitted_at`.
- RLS: users can only read/write their own plans, tasks, submissions. Tracks & topics readable by all authenticated.

**Edge functions** (Lovable AI, model `google/gemini-3-flash-preview`):
- `prep-placement-quiz` — generates 5 adaptive MCQs for a track, returns level estimate from answers.
- `prep-generate-plan` — given track + level + pace, returns ordered list of `daily_tasks` rows (question + exercise + matched `source_url` from `track_topics`).
- `prep-grade-submission` — takes task + user submission, returns `{score, passed, feedback, mistakes, hint}` as structured output (Zod/Output API). Awards karma via insert into `karma_events`.

**Frontend** (in `src/components/preparation/`):
- `TrackPicker.tsx` — filtered by `profiles.branch` + `interests`, AI track always pinned.
- `PlacementQuiz.tsx` — reuses look of existing `ProgressiveQuiz` styling.
- `PlanSetup.tsx` — pace selector + generated outline preview.
- `DailyTaskScreen.tsx` — question card, source-link button, submission box, AI-feedback panel.
- `LearningProgress.tsx` — streak calendar, level badge, karma earned, "next" CTA.
- Replace current `PreparationScreen.tsx` routing to enter the new flow when a user has no active plan, else resume.

**Integration**:
- Karma points flow into existing `karma_events` → `profiles.karma_total` via existing `sync_karma_total` trigger (add new enum values to `karma_action` if needed).
- Hook into `BottomNav` "Prepare" entry (already exists).
- "Read source" links open `source_url` in a new tab via `<a target="_blank" rel="noopener">`.

## Verification approach
AI grades each submission with structured output (score, passed, feedback, mistakes, hint). User sees clear explanation. Threshold to pass: 70/100. Failed attempts don't block — user can retry same day for partial karma.

## Out of scope (v1)
- Code execution sandbox (we rely on AI judging, not test cases).
- Multiplayer / leaderboard for tracks (karma already feeds the global leaderboard).
- Offline mode.
